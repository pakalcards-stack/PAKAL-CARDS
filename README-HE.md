# פק״ל v5

שיפורים בגרסה זו:
- הוסרה המסגרת החזותית מאזורי הלחיצה; האזורים שקופים לחלוטין ומיושרים לעיצוב.
- תמונת ההדמיה הומרה ל-WebP והוקטנה משמעותית לשיפור זמן טעינה.
- כל תמונות המשתמש הומרו ל-WebP בגדלים המתאימים לתצוגת Web.
- נוסף מסלול "עמק המעיינות" מהתמונה שסופקה.
- שולבו תמונות דמויות באזור ייעודי כהה המתאים לשפה החזותית.
- נשמר Next.js 15.5.29 המתוקן עבור Vercel.

להעלאה: החלף את כל קבצי המאגר בתוכן החבילה, מחק package-lock.json ישן, בצע Commit והמתן לפריסה חדשה.
