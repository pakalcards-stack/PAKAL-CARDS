# פק״ל Pixel Perfect v3

גרסת בסיס שנועדה להיראות זהה להדמיה שסופקה. ההדמיה עצמה מוצגת כמשטח חזותי אחיד, ומעליה אזורי לחיצה נגישים עבור הניווט, הרכישות ושלושת כרטיסי הפעולה.

## הפעלה

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

## חשוב להמשך

גרסה זו מיועדת לאשר קודם את המראה המדויק. לאחר אישור חזותי, יש לפרק את המשטח לרכיבי React אמיתיים ולחבר תוכן, מסלולים, עגלה, רכישה, FAQ וטופס קשר בלי לשנות את המראה.
