# Mobile QA checklist
Target widths: 320, 360, 390, 430, 768 px.

- Header: 64 px high; logo fully visible; menu and cart are 44x44 px.
- Homepage hero: original supplied image shown uncropped on phones with `object-fit: contain`.
- Routes: 82vw touch cards, scroll snap, no whole-page horizontal overflow.
- Rules: readable 16 px body text, compact parchment cards, RTL lists.
- Admin: 16 px form fields to prevent iOS zoom; full-width controls.
- Tablet/Desktop: full navigation restored from 761 px.
